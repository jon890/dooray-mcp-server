# ADR 0003: 상태와 삭제 안전 정책

상태: 승인됨

## 결정

서버는 상태 디렉터리에 멱등 기록, 확인 토큰, 임시 리소스, 선택 캐시를 저장한다.
되돌릴 수 없는 작업은 준비와 확정 두 단계로만 실행한다.

삭제 확인 토큰은 기본 5분 동안만 유효하다.
토큰은 대상, 입력 정규형, 대상 스냅숏, 실행 주체 지문에 결합한다.

## 근거

MCP 서버는 TTY 확인을 사용할 수 없다.
CLI의 `--yes`를 그대로 옮기면 호출자가 실수로 삭제를 실행하기 쉽다.

또한 생성, 발송, 삭제 요청은 응답이 유실되면 외부 효과가 생겼는지 알 수 없는 구간이 있다.
이때 자동 재시도하면 중복 생성이나 중복 발송이 발생할 수 있다.

## 결과

변경 도구는 `request_id`를 받는다.
같은 입력의 중복 요청은 합치고, 다른 입력에 같은 키를 쓰면 거부한다.
불명확한 외부 효과는 `OUTCOME_UNKNOWN`으로 반환하고 자동 재시도하지 않는다.

삭제 확정은 토큰 만료, 대상 불일치, 대상 상태 변경을 각각 거부한다.
Dooray API가 조건부 삭제를 제공하지 않는 대상의 남는 경쟁 조건은 결과와 문서에 명시한다.
