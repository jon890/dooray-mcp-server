# ADR 0002: 도구 프로필 전략

상태: 승인됨

## 결정

서버는 세 도구 프로필을 제공한다.

| 프로필 | 도구 수 | 결정 |
| --- | ---: | --- |
| `compact` | 12 | 장기 기본값이다. CLI 66개 기능을 도메인별 `operation`으로 제공한다. |
| `legacy` | 20 | 기존 19개 도구와 PR #28의 위키 댓글 목록 도구를 유지한다. |
| `all` | 32 | 전환 검증용으로 두 집합을 함께 등록한다. |

프로필은 `DOORAY_MCP_TOOL_PROFILE`로 시작 시 한 번 선택한다.
실행 중 도구 목록은 바꾸지 않는다.

## 근거

CRUD 단위로 도구를 계속 늘리면 MCP 클라이언트의 도구 선택 비용이 커진다.
반대로 모든 기능을 하나의 범용 도구로 합치면 권한, 재시도, 파괴성, 파일 전송 경계가 흐려진다.

12개 도메인 도구는 업무, 댓글, 첨부, 위키, 메일, 메신저처럼 위험 경계가 다른 영역을 분리한다.
각 도구 안에서는 `operation` 판별 합집합으로 입력을 엄격히 나눈다.

## 결과

기존 호출자는 `legacy`로 유지한다.
신규 호출자는 `compact`를 사용한다.
마이그레이션 기간의 호환 검증은 `all`에서 수행한다.
